# Siri Bio Bot

A semantic RAG portfolio chatbot API powered by FastAPI, ChromaDB, SentenceTransformers, and Groq.

### Endpoints
- `GET /` - Health check
- `POST /chat` - Chat with Siri portfolio bot
- `GET /docs` - Interactive Swagger documentation
